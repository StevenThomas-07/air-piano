# 🎹 Air Piano by Steven Thomas

An interactive Virtual Air Piano web application powered by **MediaPipe Hand Tracking**, **OpenCV**, and **Gradio**.

### Features:
- **Hand Tracking**: Detects index finger tip via webcam feed.
- **8 Major Scale Notes**: Plays C4 to C5 piano notes automatically when entering virtual columns.
- **Visual Feedback**: Highlights active key columns on video preview.

Created by **Steven Thomas**.
